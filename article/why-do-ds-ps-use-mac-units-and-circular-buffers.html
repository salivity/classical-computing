Why do DSPs use MAC units and circular buffers?

Digital signal processors include specialized multiply-accumulate units and circular addressing buffers to execute real-time signal processing algorithms with deterministic timing and high throughput. Unlike general-purpose processors optimized for branching and irregular memory access, digital signal processors are tailored for repetitive arithmetic over continuous streams of sampled data.

The Role of Multiply-Accumulate Units

Many fundamental signal processing operations—such as finite impulse response (FIR) filtering, infinite impulse response (IIR) filtering, convolution, and the Fast Fourier Transform (FFT)—rely on computing sums of products. For an \(N\)-tap FIR filter, each output sample \(y[n]\) is calculated as:

\[y[n] = \sum_{k=0}^{N-1} h[k] \, x[n - k]\]

where \(h[k]\) represents the filter coefficients and \(x[n - k]\) represents the delayed input samples.

On a general-purpose processor, each term in this summation typically requires separate instructions to fetch operands, multiply them, add the result to a running total, and update loop counters. A hardware multiply-accumulate (MAC) unit combines multiplication and addition into a single operation, often completing one MAC per clock cycle through pipelining. Dedicated wide accumulator registers also provide extra guard bits to prevent overflow during long summations without requiring frequent scaling.

The Role of Circular Addressing Buffers

Signal processing algorithms operate on sliding windows of recent samples. In a standard linear buffer, shifting \(N\) samples in memory every time a new sample arrives requires \(O(N)\) memory moves, which wastes cycles and memory bandwidth.

Circular addressing hardware solves this by treating a contiguous block of memory as a ring. When a pointer reaches the end of the allocated buffer, the hardware automatically wraps it back to the start address using modulo arithmetic:

\[\text{addr}_{\text{next}} = \text{base} + \left( (\text{addr}_{\text{current}} - \text{base} + \text{step}) \bmod L \right)\]

where \(L\) is the buffer length. Because this wrap-around happens in hardware as part of the address generation unit, the processor avoids conditional branch instructions and software modulo checks. This keeps the instruction pipeline full and guarantees constant-time memory access for every sample.

Real-Time Determinism and Efficiency

In classical computing, digital signal processors must often meet strict real-time deadlines where missing a sample window causes audio glitches, dropped communications, or control-loop instability. By pairing single-cycle MAC units with zero-overhead circular buffers—and often supporting dual-memory fetches in the same cycle—DSPs sustain high arithmetic density while keeping clock speeds and power consumption low compared to general-purpose CPUs.
